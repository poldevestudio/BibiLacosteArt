# Reglas y Pautas para Agentes de IA en BibiLacosteArt

## REGLA ESTRICTA DE CONTROL DE VERSIONES (GIT)

> [!IMPORTANT]
> **NO EJECUTAR `git push` BAJO NINGUNA CIRCUNSTANCIA.**
> - El usuario (Polo) gestiona y ejecuta todos los `git push` al repositorio remoto de forma 100% manual.
> - Ningún agente de IA debe ejecutar comandos automáticos de `git push`, `git push origin`, ni forzar subidas remotas.
> - Los agentes solo pueden editar código, verificar localmente y revisar `git status` / `git diff`. La publicación a producción queda reservada al usuario.
